# MCD Documentation

This directory tracks the private Metal-CUDA prefill disaggregation experiment.

- `USAGE.md`: how to run the measured handoff flow.
- `RESULTS.md`: measured benchmark results and pass/fail status.
- `PLAN.md`: project stage gates and remaining work.
- `DESIGN_NOTES.md`: architecture notes and future backend direction.
- `COMMANDS.md`: exact command history and environment references.
- `TROUBLESHOOTING.md`: known failure modes and recovery checks.
